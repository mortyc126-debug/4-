Необрезанные листы ассетов от пользователя — держим их здесь, а не в
одноразовой песочнице, потому что окружение сессии периодически
сбрасывается и теряет всё вне git. Сюда не ссылается ни один экран игры
напрямую (в статике не будет запрошен браузером, веса не добавляет
реальным игрокам) — источник для вырезки конкретных элементов по мере
реальной надобности той же связной-области техникой, что и раньше
(scipy.ndimage.label по альфа-каналу).

- sheet-kit-a.png — большой набор: рамки/панели, ленты-баннеры (лев/орёл/
  олень), ресурсные иконки, монеты, гербы-щиты с разными символами, короны,
  иконки оружия, медальоны, компас/карта, здания, полоски прогресса,
  кнопки.
- sheet-kit-b.png — второй набор: похожие рамки/панели, ленты-свитки,
  восковые печати с лентами, гербовые знамёна (лев на синем/красном/
  зелёном/белом), щиты, ресурсы (золото/дерево/камень/кристаллы), иконки
  действий (поиск/шестерня/меч/дом/замок/трофей/флаг), рамки портрета с
  лавровым венком, полоски прогресса (зелёная/синяя/красная/жёлтая),
  звёздный рейтинг, круглые бейджи с числами, предупреждение/инфо,
  пузыри диалога.
