# Прогон Edge Function на своей машине

Функции в `supabase/functions/*` написаны под Deno и живут в Supabase. Когда
в игре что-то не срабатывает, единственным способом посмотреть, падает ли
функция, были логи в Dashboard — то есть надо сперва выкатить, потом
воспроизвести, потом искать.

Здесь функция запускается прямо тут, на подставной базе: настоящий код
функции, настоящее состояние игрока, а вместо Postgres — маленькая
in-memory база с фильтрами (`fakedb.mjs`). Видно и исключение со стеком, и
что именно функция записала в состояние.

    node tools/fnlab/run.mjs mp-tick   build      # улучшение здания
    node tools/fnlab/run.mjs mp-tick   build-new  # постройка с нуля
    node tools/fnlab/run.mjs mp-join   poll       # обычный опрос
    node tools/fnlab/run.mjs mp-join   legacy     # старое состояние без новых полей

Чего стенд НЕ проверяет: настоящие RLS, настоящие типы колонок, гонки за
строку и сеть. Он отвечает ровно на один вопрос — «падает ли код функции на
таком состоянии» — и на него отвечает честно.
